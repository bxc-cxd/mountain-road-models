# 本地运行

安装 Python 3.12 后，在本目录运行：

```text
python -m pip install -r requirements.txt
python verify.py
python run.py --input examples/simulated_panel.xlsx --output results_demo --mode demo --bootstrap-reps 20 --workers 2
```

示例工作簿为独立模拟数据，运行结果不代表论文估计。实际数据分析使用：

```text
python run.py --input "实际工作簿的完整路径.xlsx" --output "本地结果目录" --mode study --workers 4
```

正式分析默认为2,000次自助抽样。数据字段、评分计算口径及输出位置见 README.md，
数值比对命令见 VALIDATION.md。保留代码文件名中的下划线，文件名须与导入语句一致。
